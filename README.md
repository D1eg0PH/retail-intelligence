# Retail Intelligence

Sistema inteligente para apoyar la toma de decisiones de compra en tiendas de abarrotes mediante el análisis de inventario y ventas exportadas desde Eleventa.

## Estado del proyecto

🚧 En desarrollo

## Tecnologías

- PostgreSQL
- ASP.NET Core Web API
- Next.js
- n8n
- Docker

## Objetivo del MVP

- Importar inventario desde Eleventa.
- Importar ventas.
- Analizar rotación de productos.
- Generar pedidos sugeridos por proveedor.
